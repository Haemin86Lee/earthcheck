# EarthCheck (지구과학 서술형 과제 평가 시스템) - Streamlit 뼈대

화면 기획안(pptx) 22개 슬라이드를 기반으로 만든 Streamlit 프론트엔드/백엔드 뼈대입니다.

## 🆕 이번 업데이트 (UI/UX 리뉴얼)

기존의 좌측 사이드바 메뉴를 **상단 고정 네비게이션 바(top navigation bar)** 중심 구조로 전면 개편하고,
전체 화면에 모던한 디자인 시스템을 적용했습니다.

- `ui.py` : 전역 디자인 시스템 모듈 (신규 추가)
  - 색상/타이포그래피/버튼/카드/뱃지 등 공통 스타일을 CSS로 한 번에 관리
  - `render_topnav()` — 로고 + 메뉴 + 로그인 사용자 정보/로그아웃이 한 줄에 배치되는 상단 고정 바
  - `page_header()` / `badge()` / `empty_state()` / `card()` 등 재사용 UI 컴포넌트
- 로그인 전 메인 화면을 히어로 섹션 + 기능 카드 3종으로 리디자인
- 로그인/회원가입 화면을 중앙 정렬 카드 폼으로 리디자인
- 교사/학생 화면 모두 좌측 사이드바 제거 → 상단 네비게이션 바로 전환
  - 교사: 🏠 홈 · 👥 학생관리 · 📋 과제관리 · 🔍 문항검토 · 📊 결과리포트 (기존 사이드바 5개 메뉴 1:1 유지)
  - 학생: 🏠 홈 · 📤 과제제출 · 📝 이해도확인 · 📊 결과확인 · ⚙️ 개인정보 (기존 사이드바 5개 메뉴 1:1 유지)
- 목록/표 형태 화면을 카드형 행(row-card)으로 재구성, 상태값은 색상 뱃지로 표시
- 시험(재검사) 화면에 진행률 바 + 남은시간 뱃지 추가
- **회원가입 버그 수정**: "구분(학생/교사)" 선택을 `st.form` 밖으로 이동해, 선택 즉시
  학생 전용 입력칸(학년/반/번호)이 정확히 나타나거나 사라지도록 수정했습니다.
  (기존에는 폼 안에 있어 "가입하기"를 누르기 전까지 화면이 갱신되지 않아 혼란을 줄 수 있었습니다.)
  아울러 공백 입력 방지, 비밀번호 최소 길이 검사, DB 저장 중 오류가 나도 화면이 죽지 않고
  원인을 바로 보여주도록 예외 처리를 추가했습니다.
- 기능/데이터 흐름, DB 스키마, 인증 로직 등 **기존 백엔드 로직은 변경하지 않았습니다**
  (`auth.py`, `database.py`, `mock_ai.py`, `config.py`는 기존과 동일)

## 🆕 과제 조회 화면 개편 (배포 워크플로우 추가)

- **하나의 표로 통합**: 헤더 행부터 과제 목록까지 하나의 표 컨테이너 안에서 얇은 구분선으로만 행이 나뉘도록 변경했습니다.
- **생성순 정렬**: 기본 정렬은 먼저 생성된 과제가 위로 오도록(오름차순) 바뀌었습니다.
- **순서 변경(▲/▼)**: 실제 마우스 드래그 라이브러리를 검토했지만, 이 앱의 여러 페이지를 오가는 구조와 함께 쓰면 이따금 오류가 발생해 제외했습니다. 대신 각 행의 ▲/▼ 버튼으로 순서를 바꾸면 즉시 저장되는, 훨씬 안정적인 방식으로 구현했습니다.
- **배포 워크플로우 추가**: 과제를 새로 만들면 처음에는 '배포전' 상태이며, "배포하기" 버튼을 눌러야 학생 화면(홈/과제제출/이해도확인/결과확인)에 나타납니다. "배포 취소"를 누르면 다시 학생에게 보이지 않습니다.
- **과제명 링크화**: '상세보기' 버튼 대신, 과제명 자체가 링크처럼 동작합니다(마우스를 올리면 밑줄, 클릭 시 상세보기로 이동).
- DB에 `sort_order` 컬럼이 추가되었고(기존 DB 파일에도 앱 실행 시 자동으로 안전하게 추가됩니다), `database.py`에 `list_published_assignments()` / `set_assignment_status()` / `set_assignment_order()` 함수가 새로 생겼습니다.


```powershell
# 1) 프로젝트 폴더로 이동
cd earthcheck

# 2) (최초 1회) 필요한 패키지 설치
pip install -r requirements.txt

# 3) 앱 실행
streamlit run app.py
```

실행하면 브라우저가 자동으로 열리며, 최초 실행 시 `earthcheck.db` (SQLite 파일)가
자동 생성되고 데모용 샘플 데이터(교사 1명, 학생 6명, 과제 1건)가 채워집니다.

## 🆕 문항검토·제출현황·결과리포트 개선

- **문항검토**: 과제를 제출하지 않은 학생은 [문항보기]/[근거보기] 대신 비활성화된 [과제 미제출] 버튼으로 표시됩니다.
- **버그 수정**: 학생이 같은 과제를 재제출하면 제출현황 화면에서 `StreamlitDuplicateElementKey` 오류가 나던 문제를 고쳤습니다. 이제 학생별로 항상 가장 최근 제출 1건만 사용합니다.
- **결과 리포트**: 재검사 점수는 이제 "정답 개수/과제 생성 시 설정한 총 문항수"로 표시되고, 과제 신뢰도는 숫자(%) 대신 정답 비율에 따라 상(67~100%, 초록)/중(34~66%, 주황)/하(0~33%, 빨강) 카드로 표시됩니다. 목록은 실제로 재검사를 완료한 학생만 조회됩니다.
- **AI 피드백**: 이제 `mock_ai` 대신 실제 학생의 점수·신뢰도·오답 내용을 근거로 Claude API가 피드백(문항 생성 근거/이해도 판단/보충·심화 제안)을 생성합니다. 생성된 피드백은 교사(결과 리포트)와 학생(결과 확인 화면) 모두에서 볼 수 있습니다.
- **추가 과제 제출**: AI가 제안한 보충·심화 과제에 대해 학생이 결과 확인 화면에서 PDF를 선택적으로 제출할 수 있습니다. 결과 리포트의 "추가 과제" 칸에는 제출한 학생만 📄 다운로드 아이콘이 뜨고, 제출하지 않은 학생은 빈칸으로 보입니다.

## 🆕 문항검토 화면: 실제 생성형 AI 연동

- 이제 "문항보기"를 처음 누르면, 그 학생이 실제로 제출한 PDF 답안을 읽어(`ai_engine.py`), Anthropic Claude API로 실제 5지선다 객관식 문항을 생성합니다(과제 생성 시 설정한 "재검사 문항 수"만큼). 한 번 생성된 뒤에는 다시 누르면 재생성 없이 기존 문항을 그대로 보여줍니다.
- **실행 전 준비물**: 터미널에서 `ANTHROPIC_API_KEY` 환경변수를 설정해야 합니다.
  - Windows(PowerShell): `$env:ANTHROPIC_API_KEY = "sk-ant-..."`
  - macOS/Linux: `export ANTHROPIC_API_KEY="sk-ant-..."`
  - 키가 없거나 학생이 아직 과제를 제출하지 않은 경우, 화면에 안내 메시지가 뜨고 앱이 멈추지 않습니다.
- "문항보기": 생성된 문항을 표로 확인하고, 문항/보기/정답을 직접 수정하거나 삭제할 수 있습니다.
- "근거보기": 각 문항이 학생 답안의 몇 페이지, 어떤 문장을 근거로 만들어졌는지 실제 인용문과 함께 보여주고, 학생 과제물 PDF를 바로 다운로드할 수 있습니다.
- 새 패키지: `anthropic`, `pypdf` (requirements.txt에 추가되어 있습니다).

## 폴더 구조

```
earthcheck/
├── app.py                # 진입점 · 전체 화면 라우팅 · 전역 CSS 주입
├── ui.py                  # 디자인 시스템(신규) · 상단 네비게이션 바 · 카드/뱃지 컴포넌트
├── config.py                # 경로/상수 설정
├── database.py                # SQLite 스키마 + 모든 CRUD 함수
├── auth.py                      # 회원가입/로그인/세션/비밀번호 해시
├── mock_ai.py                     # AI 연동 더미(mock) 함수 - 실제 연동 시 이 파일만 교체
├── views/
│   ├── common_views.py               # 메인/회원가입/로그인 (슬라이드 1~3)
│   ├── admin_views.py                   # 관리자(교사) 12화면 (슬라이드 4~15)
│   └── student_views.py                    # 학생 7화면 (슬라이드 16~22)
├── uploads/                                  # 학생이 제출한 PDF 저장 폴더 (자동 생성)
└── earthcheck.db                               # SQLite DB 파일 (최초 실행 시 자동 생성)
```

## 지금 단계에서 "더미(mock)"로 처리된 부분

- **AI 문항 생성 / AI 피드백 / 표절률 검사** → `mock_ai.py`에 더미 함수로 구현되어 있습니다.
  실제 Claude/OpenAI API로 교체할 때는 이 파일 안의 함수 **내부 구현만** 바꾸면 되고,
  `views/` 쪽 화면 코드는 수정할 필요가 없도록 설계했습니다.
- **단답형 채점**은 현재 문자열 단순 비교로 처리됩니다 (`mock_ai.grade_short_answer`).
- **재검사 시험 타이머**는 화면이 다시 그려질 때(문항 이동 시 등)마다 남은 시간을 다시
  계산하는 방식입니다. 매 초 자동으로 화면을 갱신하려면 `streamlit-autorefresh` 같은
  별도 패키지 설치가 필요합니다 (현재는 포함되어 있지 않습니다).
- **비밀번호 해시**는 표준 라이브러리 `hashlib.sha256`을 사용했습니다. 운영 환경에서는
  `bcrypt`/`argon2` 등 느린 해시 알고리즘 사용을 권장합니다.
- 관리자 화면의 일부 "수정" 버튼은 뼈대 단계라 비활성화(`disabled=True`)되어 있습니다.
